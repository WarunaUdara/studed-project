# ADR 0001: Record Architecture Decisions

- **Status**: Accepted
- **Date**: 2026-08-06

## Context
As StudEd grows across multiple Go microservices and React frontend packages, technical choices and trade-offs need to be documented for clarity and onboarding.

## Decision
We will use Architectural Decision Records (ADRs) in markdown format inside `docs/adr/` following standard Nygard format.

## Consequences
- Architectural decisions are version-controlled alongside code.
- Trade-offs are transparent to developers and auditors.
